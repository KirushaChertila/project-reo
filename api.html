Авторизация

Схема авторизации пользователей идентична протоколу OAuth 2.0

Тип токена: Bearer

В заголовках необходимо указывать Content-Type: x-www-form-urlencoded

Метод: POST

Url: /connect/token

Параметр Значение Описание
grant_type password -
username - Имя пользователя
password Пароль -
client_id - Для каждой ИС будет свой
client_secret secret -

Пример запроса:

{
"method": "POST",
"header": [],
"body": {grant_type=password&username=<username>&password=<password>& client_id=<client_id>& client_secret=<client_secret>}
